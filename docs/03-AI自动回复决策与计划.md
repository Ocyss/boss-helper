# AI 自动回复决策记录与计划

> 状态：持续更新<br>
> 更新日期：2026-08-11

## 当前结论

| 编号 | 状态 | 决策 |
| --- | --- | --- |
| D-001 | 已确认 | AI 只回答有确定依据的内容；拿不准时拒答并通知本人。 |
| D-002 | 已确认 | 回复能力由 BossHelper 插件直接承担，复用现有模型与 Prompt 配置。 |
| D-003 | 已废弃 | Hermes、自定义 `boss_helper` Platform、本机桥接和 `lark-cli` 不再属于回复链路。 |
| D-004 | 已确认 | HR 新消息自动触发；用户也可选择已有会话主动触发一次。 |
| D-005 | 已确认 | 回复发送复用当前 BOSS MQTT/WS，不创建第二条连接。 |
| D-006 | 已确认 | Prompt、确定性校验和本地知识库分层；模型输出不能直接发送。 |
| D-007 | 已确认 | 本地知识采用结构化轻量配置，不在 MVP 引入向量库或 RAG 服务。 |
| D-008 | 已确认 | 提供草稿与自动发送两种模式，默认草稿；自动发送仍需通过本地校验。 |
| D-009 | 已确认 | 拒答或异常后持久化暂停当前会话，人工恢复前不继续自动回复。 |
| D-010 | 已确认 | 浏览器通知为本地兜底；飞书通知通过智能体应用 App ID/App Secret 直连 OpenAPI。 |
| D-011 | 实现约束 | 当前历史不完整，只能使用摘要和本次运行期间消息，并明确传给模型。 |

## 已完成编码

- 会话摘要自动载入、WS 文本解析、方向判断、消息 ID 去重和 2.5 秒合并。
- 会话对应 JD 补充、最近可见聊天与已确认知识的提示词上下文。
- 严格 JSON/动作/证据/长度校验，以及草稿、发送、忽略、人工接管状态。
- 会话级暂停持久化、手动处理入口、暂停/恢复、草稿复制及发送前基础过期检查。
- 飞书后台鉴权、Token 缓存、机器人文本通知和配置测试入口。

## 下一步

1. 由用户重新构建扩展并完成人工验收，逐项记录真实结果。
2. 从聊天页网络请求确认单会话完整历史接口、分页和消息类型。
3. 在现有“消息 ID 已变化即作废”基础上，补充更细的用户手动回复与草稿版本提示。
4. 根据验证结果补充并发上限、重试、日志和发布迁移策略。

## 明确不做

- 不恢复 Hermes Platform 或额外常驻桥接服务。
- 不把飞书群聊当作 AI 请求/响应中转通道。
- 不向模型暴露 BOSS Cookie、登录 Token、飞书 App Secret 或原始 WS 帧。
